# Milo next pass: primary-source notes, 2026-09-12

DDGS supplies a no-key Python search interface returning title/href/body. Use explicit `duckduckgo,brave` backends rather than `auto`, which includes additional sources such as Grokipedia. The package describes itself as educational. It scrapes public search endpoints; availability and page changes are real limitations, not a guaranteed free search API. Sources: https://github.com/deedy5/ddgs and https://github.com/deedy5/ddgs/blob/main/ddgs/ddgs.py and https://github.com/deedy5/ddgs/blob/main/ddgs/engines/duckduckgo.py . Individual request timeouts do not guarantee a total deadline. Do not claim its safesearch parameter is enforced by every backend. A failed search must remain a visible failure.

Pocket TTS v3.1 has named voice states, no dedicated robot preset. Cache states via `get_state_for_audio_prompt` and reuse the model. Candidate auditions are marius, javert, bill_boerst, stuart_bell, with alba retained as the original reference. The candidate sources are donation/Voice-Zero collections catalogued as CC0. Their suitability is an audition question, not an established voice-quality score. Sources: https://github.com/kyutai-labs/pocket-tts/blob/v3.1.0/pocket_tts/utils/utils.py and https://github.com/kyutai-labs/pocket-tts/blob/v3.1.0/README.md and https://huggingface.co/kyutai/tts-voices/blob/main/README.md . Other library presets have different source licenses; do not generalize CC0 to the whole catalog.

Implementation decision: bounded search snippets and visible public links, no webpage fetching or browser agent. Explicit query only; do not send conversation history or microphone audio to a provider. Voice synthesis and answers remain local. Excerpts enter the prompt as untrusted source data, with strict instructions to distinguish them from instructions or established facts.

GPT OSS uses `think: low|medium|high` in Ollama; its reasoning cannot be disabled completely. Source: [Ollama thinking documentation](https://docs.ollama.com/capabilities/thinking). Implementation retains low effort, reserves output budget for reasoning plus answer, and streams only answer content to speech. It never displays or speaks the private reasoning field.
